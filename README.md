NEON BAY — a top-down open-world crime game. You are Jax Carter, a getaway driver with a $10,000 debt. Explore the fictional coastal city of Neon Bay on foot and by car, steal cars, outrun the police at five wanted levels, fight the Red Vipers gang, and run five story missions for your fixer Mara to pay the debt off. Traffic, pedestrians, a minimap HUD, save games and synthesized sound included. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.

### Controls

- **W A S D** — move on foot / drive
- **Mouse** — aim, **Click** — shoot
- **E** — enter / exit a car, grab mission items
- **Space** — handbrake
- **P** — pause, **M** — mute
